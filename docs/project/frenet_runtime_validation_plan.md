# Frenet 候選驗證與查詢設計

更新日期：2026-10-29。現況與驗收數字見[完成總結](CHANGELOG.md)，任務與通過條件見[算法執行計畫](CHANGELOG.md)。本文件維護查詢設計，歷史量測見[報告索引](../README.md#歷史實驗與驗收報告)，不再追加每批進度。

## 現行範圍

主要驗收為 MY map／候選前視 3 m，PP 前視 0.6 m；ESP 5／6／7 m 為跨圖／歷史對照，40 m 為歷史／壓力對照。候選不接管中線控制，主入口查詢／生成預設仍 exact／optimized。

候選生成以 d(s) 表達，載入同版本 CSV 樣本、reference_curve.json 與原圖。CSV 用於控制路徑、展示及來源核對；任意 s 的參考線由同版樣條求值，邊界使用原 occupancy 精確格子射線。CSV 邊界插值、跨 s 連續有效域及跨程序快取持久化尚未批准。

## 已實作查詢能力

| 模式／元件 | 能力 | 限制 |
|---|---|---|
| exact | 保留原幾何查詢與驗證對照 | 主預設，不能以舊效能報告代表所有來源 |
| reused_exact | 同次生成共用精確參考量／邊界，批次準備參考資料 | 不量化輸入、不改原判定，仍有新位置成本 |
| fast_with_fallback | 精確 s 道路表、三態範圍、程序內跨次快取；可確認橫向範圍免反向投影，uncertain 回退 | 固定 s 的範圍依據不等於相鄰 s 區段依據 |
| fixed_grid_with_fallback | 固定道路網格與滑動視窗；因無替代依據，保留原網格核驗 | 舊聯集原型效能／覆蓋未通過，不作推薦加速 |
| fixed_grid_lookup | 固定 5 cm 弧長定位點重用，提供括區／初值，批次反解原積分方程 | MY／ESP 候選仍原 2.5 cm；各實際 s 重算參考線／曲率及原圖邊界，非邊界插值或曲線合格結果重用 |

固定定位反解須確認括區符號及參數寬度，不能只以殘差小判定；不確定者回退原 scalar u_at_s。幾何／地圖／積分實作改變使快取失效，非標準來源／積分實作關閉批次捷徑。最新模式已有兩圈與原密度核驗，但仍逾時；G1 道路邊界跨 s 重用與 G2～G5 尚未完成。

## 資料、快取與區段依據

- 同一 geometry_id、frame、s 原點／正向載入中線、邊界 CSV、樣條與 map，核對來源及檔案雜湊，不另建未對齊中線。
- 三態區分 checked_valid、checked_invalid、uncertain；未知範圍不能快速接受。正確／錯誤幾何結果可快取，solver failure／timeout 不當作永久道路無效。
- 道路範圍與 Frenet 可接受域分開。道路內仍可能違反 J、投影唯一性或來源一致性，不能只比較 d 與邊界就宣稱通過。
- 靜態 key 包含 geometry／map／政策及精確 s，點查詢再含 d／margin；曲線相關 key 包含完整係數／導數、起點／端點與限制。輸入不任意四捨五入，容量有上限，版本變動失效。
- 跨 s 區段判定須涵蓋道路縮窄、射線切換、歧義、J／曲率、曲線導數及相鄰折線；有限端點／中點測試不構成保守界證明。只對已覆蓋條件取代舊檢查，其餘局部精確回退。
- 視窗道路重疊率、定位快取命中率與新曲線驗證重用率分開。道路資料相同不能沿用改變後曲線的通過旗標。

## 執行期流程與回退

1. 來源 pose／時間經定位與進度檢查，取得實際 s／d／航向，保留起點位置與 yaw 閘門。
2. 五候選共用 s 的參考線、法向量、曲率／導數及道路資料，依選定模式查詢。
3. 依原限制檢查道路餘裕、斜率、曲率及 J；可確認者快速判定，uncertain 仍精確核驗。
4. 批次前向 XY 用於記錄／繪圖；保留必要的反向來源一致性與原圖折線 occupancy 檢查。
5. 記錄拒絕與回退原因、查詢／求解耗時、來源及結果版本；直接生成不合格時依設定進行原方法修正。

| 情況 | 行為 |
|---|---|
| 來源／版本不符、檔案損壞 | 拒絕，不用回退掩蓋不一致 |
| 誤差界未知、邊界帶、無可靠區段 | 精確查詢；失敗明確拒絕 |
| 歧義、接縫未核對、低 J | 完整確認或拒絕，不直接快速接受 |
| 明確違反已確認限制 | 拒絕並保存原因 |
| 地圖／動態障礙改變 | 靜態表不可替代更新後障礙檢查 |

## 後續順序與完成界線

下一項先改善精確邊界批次查詢及資料複製，維持原網格與判定；再建立區段依據／局部回退、前一步解初值及修正策略，最後接入可中止整組截止。任務集中於[執行計畫第 8 節](CHANGELOG.md)及[G1～G5](CHANGELOG.md)。

每階段同版本、同來源、同前視比較冷／熱快取與移動序列，保留原 exact／原密度獨立核驗；報合格覆蓋、品質與延遲尾端。整組五候選共享 0.1 s 控制步預算，另留定位、控制與記錄餘量，未完成者須明確拒絕，晚到資料不得冒充當下結果。目前同步規劃會暫停模擬時間，時間觀察不等於已實作 deadline。

本方案不新增候選接管、對手預測或 MPC，也不批准完整車身／動態安全。有限取樣、兩圈無碰撞與中位數改善不構成全道路連續域或即時保證；各有效性旗標依實際驗證分開維護。
