# R3：側向大係數原因核對

日期：2026-10-14。本次只診斷，不修改控制器、選點、rank cutoff 或 plant。

對象：固定 ATV 驗證最差窗口 raw 3888，名義歷史 seed 1921，前兩個模型。式 (13) 側向 regressor 排列 `[vx,vy,r,delta,1]`。按保存的 80 個 raw ID，重新讀取狀態、正確 outgoing command 與下一步 target，獨立重建距離、kernel 與加權矩陣。

## 確認結果

以明寫的截斷 SVD 偽逆重算，沒有呼叫原來的 `np.linalg.lstsq`。所得 vy/r 係數與保存係數的相對差為 2.2e-16～5.6e-16，保留方向的 normal-equation residual 約 2.5e-12～1.0e-9。證據支持：此窗口係數符合目前 WLS 與 rcond=1e-8 的求解規格，不是已發現求解器／係數排列計算錯誤。這不代表全部程式和資料契約已由本次單一窗口證明正確。

第一步 80 筆不同 ID 的樣本中，vx range 約 5.17e-9 m/s、vy range 約 5.66e-7 m/s、r range 約 4.64e-7 rad/s；delta range 約 .01349 rad。80 筆樣本不是 80 個獨立的動態方向。

五欄加權矩陣奇異值約 `[12.1266,.0300199,2.02725e-6,6.66e-14,1.23e-16]`；按現有閾值 rank=3，不能唯一決定五個係數。保留子空間的條件數約 598 萬，下一步約 626 萬。即便保留三個方向，最弱方向也非常敏感。

診斷中只將加權 target 沿最弱保留方向改變 1e-6 的二範數，係數向量已改變約 .493／.516。此為獨立敏感度計算，不是新增歷史資料，也不是實際觀測。

結果能在近乎相同的歷史狀態上形成抵消，但離開此資料關係後，大的 A 係數會放大誤差；固定 ATV 實際已出現這種放大。局部擬合 RMSE 小不構成多步可靠性的證明。

現有 `input_identifiable` guard 只判斷轉向／加速度輸入欄是否增加 rank；它不要求所有狀態係數唯一，也不檢查保留子空間的敏感度。因此此側向 rank3 模型可以通過輸入 guard，不能把這解讀為完整 A/B/C 都可靠。

## 結論與範圍

已確認此失敗窗口具有嚴重退化／病態的局部回歸資料，當前最小範數解由它產生很大的側向狀態係數；不是「A/B/C 尚未決定」，也沒有證據把問題歸為 QP 或 PID 計算錯誤。不宣稱所有窗口都只有同一原因。
