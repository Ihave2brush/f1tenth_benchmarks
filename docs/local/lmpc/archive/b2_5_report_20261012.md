## 故障現場與修正選擇

以 B3 第171步的實際狀態、前一解、候選及固定40點，重建「第一輪有解、第二輪不可行」。現行程式 hash 與原 session 不同，這是保存現場的診斷，不稱為原版本逐位重現。

另用 HiGHS 線性可行性求解器检查同一 QP 的限制：第一輪完整限制可行；第二輪完整限制不可行。第二輪移除整組模型等式或整組終端等式可恢復可行；只移除輸入限制或只移除狀態／trust box 仍不可行，而同時移除兩者可行。保留其他限制，單獨移除終端 vy、r、e_psi、s或e_y等式可行；只移除vx終端等式仍不可行。

因此證據支持「該次線性模型、硬終端與限制共同不相容」，不支持「資料缺點」、「只有輸入上限」或「只改 warm start 就修好」。從當下量測重推演仍在第二輪失敗。所有限制移除只作離線診斷，沒有施加鬆弛命令到車輛。矩陣與結果保存在 [凍結 QP 診斷](../../../../Data/research/lmpc/b2_5_frozen_qp_20261012_003/frozen_qp_diagnosis.json)。

目前研究修正包含：

- 可按 source ID 限定模型訓練，並保存回歸奇異值／條件數。
- 可從量測狀態及延遲記憶重新推演 warm start，原 shifted 模式仍保留。
- 原物理子步＋同一 core 的幾何位置更新，避免粗時間步的累積偏差。
- 有限幅度原 PID secant 線性近似；轉向／buffer取樣0.032 rad，對應原速率3.2 rad/s × .01 s。此為跨切換區域的近似，**不是原非光滑模型的精確 Jacobian**。

原 B3 設定、PID／車模、ESP／core、B1／B2三個歷史 NPZ、N=12／K=20／P=80／dt=.1、六維硬終端與共享lambda成本保持；每次命令仍經原模型完整預演。
