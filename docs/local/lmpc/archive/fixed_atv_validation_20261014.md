# R3：依 IV-C 固定整段 ATV 的驗證

日期：2026-10-14。使用者授權按照論文方式進行。本次完成共用建模與離線驗證，未啟動車輛閉迴路、未改動 plant、Safe Set、成本或輸入限制。

## 建模流程

`paper_model.build_atv_horizon` 在各個名義狀態建立 A/B/C；整段模型建立完後，`rollout_atv` 只使用式 (15) 的 A*x+B*u+C，不用預測狀態重新回歸。

`PaperLocalLMPC` 使用同一建模函式。已有上一解時，保留 IV-C 的狀態移位與末端 candidate：`vstack([old_states[1:], candidate])`，模型先建立，再解一次 QP。第一次控制仍使用歷史 seed；連續 PP 接手 seed 的缺口仍未在本次修正。

獨立離線測試沒有上一個 QP 解，因此使用第一圈訓練歷史中、與目前觀測進度最近的完整 12 步窗口作名義 seed；靠近終點時限於訓練範圍內的完整窗口。s 僅按整數 L 對齊，不改物理速度與姿態。此為工程驗證的歷史 seed，不是論文 IV-C 所指的上一個最佳解，不宣稱已完成其閉迴路驗收。

第二圈的未來狀態不作名義軌跡、不作回歸訓練；第二圈已記錄控制僅作離線 rollout 的輸入，未來狀態僅作誤差比較。各步所選訓練 transition ID 及名義窗口來源有 assertion 與輸出紀錄。維持 P80、Q、h10、kernel、WLS、已授權的加速度 gain 初值及事前誤差門檻。

## 結果

- 56 項 LMPC 測試通過，新增驗證模型只在名義點建立、rollout 不重新辨識，以及各步 nominal 上 A*x+B*u+C 與原模型值一致。
- 99/99 個窗口均完成 12 步；不再遇到預測偏離後重新回歸而無資料的中断。
- 但單步與多步的誤差仍未通過；`passed=false`。能完成計算不等於預測正確。
- 最差窗口 raw ID 3888、名義窗口 seed 1921：第一步 r 誤差約 .0068 rad/s，第二步約 4633 rad/s，12 步約 6.49e44 rad/s。這些是失真的模型預測，不是真實車輛行駛結果。
- 該窗口第一步速度 A 的譜半徑約 46539；三組回歸 rank 為 2/3/3，局部加權 RMSE 約 .000017/.00793/.0749。局部資料擬合誤差不大，仍可能形成會放大偏差的係數。這是具體診斷證據，尚非所有失敗窗口的單一原因證明，也不能據此宣稱 PID 有問題。

輸出：`Data/research/lmpc/r3_fixed_atv_20261014_001/validation.json`，包含來源 ID、名義 states/inputs、逐步 A/B/C、辨識診斷與誤差；`preregistered_policy.json` 保存方法、資料分割、限制與門檻。
