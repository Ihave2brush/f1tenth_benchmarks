## 1. 目標與研究問題

固定使用 ESP 賽道，先用 Pure Pursuit 以 1.2 m/s 追蹤中線兩圈，收集成功行駛資料；載入這兩圈及已驗收週期延伸，重新由起點靜止開始 Local Learning Model Predictive Control（Local LMPC）實驗，逐圈更新歷史經驗。

核心問題是：**歷史成功圈構成的 Local Safe Set 與 Q-function，是否能讓車輛在 ESP 上逐圈改善路線、速度配置及圈時？**

主要成果：

- 可重現地完成「中線 PP 兩圈資料 → 新實驗靜止起跑 Local LMPC → 成功圈更新」；資料收集與實驗分開計圈，LMPC 實驗內各圈連續行駛。
- 比較固定初始終端資料與逐圈更新終端資料的 LMPC，量化學習效果。
- 解釋效能改善或失敗的原因，包括模型誤差、終端約束、致動器限制與 Frenet 有效性。
- 以生成賽車線作為次要比較，分析位置、速度及實際可達圈時的差距。

生成賽車線不得成為 LMPC 的追蹤目標、訓練標籤或終端資料來源。既有生成器採用最小曲率路線與速度配置，不稱為全域最短圈時解。

本階段不包含其他賽道、超車、ROS2 部署或實車驗證。不預先承諾逐圈圈時單調下降、全域最優或與論文相同的收斂圈數。

## 4. 狀態、控制與圈資料契約

### 4.1 六維狀態

現有物理狀態為 `[X,Y,steering,signed_speed,yaw,yawrate,beta]`，Continuous 已提供其副本。

| LMPC 狀態 | 轉換規則 |
|---|---|
| vx、vy | 按實作的速度與側滑角定義，以 `v*cos(beta)`、`v*sin(beta)` 轉到車身座標；需測試正向與低速情況 |
| r | 物理模型的 yawrate |
| e_psi、e_y | 同一 core Frenet 幾何的航向誤差與左正右負 d |
| s | core Frenet 連續進度；資料庫再依明確圈起點做座標平移 |

統一物理參考點、map frame、時間戳與 geometry_id。LMPC 不得把 Continuous 折線 s 填入 core Frenet 狀態。FrenetTracker 的 wrap_count 不等於成功完整圈數；圈資格與計時使用對齊後的 Continuous 事件。

### 4.2 控制輸入

現有 planner 介面是 `[steering,target_speed]`，動力學內部轉成加速度與轉向角速度，並保留轉向延遲。論文的 `[delta,a]` 需要明確的研究介面適配。

實作前先選定並驗收適配方式：保存命令、延遲後的目標、實際轉向角、受限後施加的加速度／轉向速率與物理後繼狀態。不得把速度命令當成加速度；現有 `accel` 欄位是否真實更新也須核對，不能只讀欄位名稱。

PP 與 LMPC 使用同一物理模型、致動器機制及限制。若 B 新增加速度入口，維持原版入口語意，並補上 B 的獨立重播。

### 4.3 成功圈與終點延伸

每個 transition 保存同一控制區間的 `(x_t,u_t,x_{t+1},dt)`。實际控制樣本與插值跨線事件分開保存，避免憑空建立精確跨線的物理樣本。

- 只有驗收通過的完整圈可成為成功圈來源；碰撞、投影失效及備援污染的圈另存診斷。
- 成本以論文的剩餘控制步數 `J_t=T-t` 表達，同時保存秒數與插值圈時；初始化事件對齊須有明確離散規則。
- 跨終點延伸需保留連續後繼資料與相應成本座標，不能把下一圈的 s 和成本直接歸零後拼接。
- 第一圈可使用實際第二圈資料延伸；第二圈未觀測的後綴不可標成實測。2026-10-08 使用者指定重用既有圈頭：允許另存有來源與模型接縫檢查的近似週期終端延伸，不生成新量測、不引用未來資料。
- 若重複任務的延伸規格需要額外初始化資料，先記錄理由並更新計畫，不能默默增加初始化圈數或把週期複製當成實測後繼。

## 5. 執行階段與驗收門檻

### B0：接線規格與局部規劃前置

- 固定 ESP 地圖／幾何版本；PP 追蹤同一 core 中線。
- 對齊 Continuous 與 Frenet 的實體起終線、方向及進度語意。
- 完成六維狀態轉換、加速度適配、紀錄與重播規格。
- 設定 10 Hz 控制，保留較細物理子步進；驗證控制時間與致動器 buffer。
- 定義 B 的局部規劃域及候選驗證流程：精確 Frenet 有效性、Cartesian 車身與動態限制。明列採樣檢查的解析度及範圍，不把有限取樣宣稱為連續證明。

**通過條件：** 語意與版本一致；短程物理重播一致；新規劃介面不繞過既有限制；每個未由論文明列的參數都有來源。

### B1：1.2 m/s 中線兩圈可行性

低速不等於能過所有彎。先檢查中線曲率與所需轉向，再做包含延遲及車身碰撞的閉迴路兩圈模擬。

特別處理原版 GlobalPurePursuit 在 `vehicle_speed < 1` 時直接回傳 `[0,4]` 的分支，避免初始化目標 1.2 m/s 被隱藏的 4 m/s 命令取代。起步策略只在研究適配層定義並保存，原控制器基準不默改。

逐段檢查：起步／停滯／倒退、實際速度偏差、中線追蹤誤差、轉向角与速率飽和、車身道路餘裕、Frenet 分支與有效性、起终點銜接。

**通過條件：** 兩個完整圈、一次 reset、零碰撞、零 Frenet 失效／進度跳躍、資料可重播；誤差和致動器飽和未導致不可接受偏離。可接受誤差／餘裕門檻在執行前記錄，不能看完結果才放寬。第二圈 flying 表現作為主要初始化圈時基準，第一圈起步暫態另列。

若不通過，先定位前視距離、轉向機制、起步或速度的原因。任何偏離 1.2 m/s 或其他論文設定都建立新設定並記錄原因；失敗圈不進成功資料庫。

### B2：Lap Database、Local Safe Set 與 Q-function

- 收集已通過 B1 的兩圈狀態、輸入及後繼資料，完成成本和終點延伸規格。
- 對兩個來源圈，各依 s 選 K=20 點；驗證局部窗口與圈座標平移。
- 建立終端凸組合：`x_N=D_data*lambda`、`lambda>=0`、`sum(lambda)=1`。`D_data` 是歷史狀態矩陣，與距離矩陣 D 區分。
- 使用相同 lambda 最小化歷史剩餘成本；保存來源 lap_id、sample_id、cost 和 successor。
- 實作上一解終端權重與歷史後繼點推進下一步終端候選的論文流程。

**通過條件：** 已知成功狀態可重建且成本一致；鄰近點及後繼索引正確；跨終點成本無不合理跳變；無未來資料引用。凸包本身不等於非線性車輛的安全保證。

2026-10-08 初版 B2 決策：離散終點取跨線後首個實測樣本，相鄰圈共享邊界；圈內成本 T-t，實測延伸保留同一 s 與有號遞減成本（負值是延伸勢函數，為明列工程規格）。原始輸入按下一 row 的 incoming trace 對齊 outgoing transition。初版 observed-only 窗口缺 successor 時拒絕。

同日依使用者修正：第三圈直接用既有兩圈歷史資料。第二圈圈頭第 1～128 個後繼樣本另存週期模板，s 加 L、成本從 -1 逐步遞減；原量測陣列不改。最後實測狀態至模板首點為 `approximate_periodic_seam`，先驗收原模型一控制步的狀態／位置／航向／轉向與延遲 buffer 誤差。之後的模板列保留 source ID／原時間，不標成新量測，整段禁止用於模型辨識。423 個窗口覆蓋 [0,L+9.6 m]，足以提供目前設定的第三圈終端歷史窗口。這是明列工程近似，未證明 MPC 遞迴可行性；不增加初始化圈數。原版精確 Frenet 權限旗標不變。

2026-10-12 方法釐清：B3 改為獨立 LMPC 實驗，重新從 core 起點靜止開始，不恢復 B1 終點。仍載入同一組前兩圈＋第二圈週期模板；歷史週期接縫維持行進狀態重用，不混入新實驗的 reset。每圈原始點數 1971／1968，K=20 是每控制步每來源圈的局部選點數。使用一致的新實驗 s 基準，不能照抄舊 acceptance 的 cycle=2 候選。新 LMPC 資料另存，完整成功後再更新來源與成本。詳細問題、數學與 NPZ 核對見重新檢視紀錄。

### B2.5：底層控制與預測模型接軌

目的：確認 LMPC 的「命令 → 致動器 → 車輛狀態」預測足以支持目前終端約束，先定位並處理 B3 第一段彎道失敗。這不是先認定原 PID 有錯；論文同樣有底層致動器控制，現階段要補的是本模擬器的輸入語意、記憶與模型適用性驗證。

**目前問題與修正理由：** B3 在 s=23.8867 m 的下一步，第一輪 QP 有解、第二輪不可行；歷史40點及後繼齊全，已執行片段沒有碰撞。原 PID 能完成 PP 兩圈，但尚不能證明近似模型能預測 LMPC 的新命令。先處理輸入／致動器模型的一致性，並比較從真實狀態重推演 warm start；局部資料適用範圍、終端記憶及各組限制須診斷後才決定改法。平均250.66 ms的耗時超標另行處理，不直接認定為不可行原因。逐項「問題 → 理由 → 修正 → 驗證」見 [B2.5 接軌計畫](b2_5_control_model_plan.md)第2節。

- 固定現有 ESP／core 版本、原車模與 PID，沿用 B1 已成功兩圈與 B2 三個 NPZ；不重收初始化圈、不更改已接受資料。
- 對齊轉向命令、延遲目標、實際轉向角／速率、加速度命令／施加值及 .01 s 子步。驗證原模型精確重播；PP 的平均加速度不直接視為精確常值輸入。
- 使用成功 PP 資料檢查一步與 N=12 自由預測，分開報告模型辨識擬合與獨立驗證；按起步、直線、彎道與跨線分類，門檻在驗證前固定。

- 保存並重建 B3 在 s=23.8867 m 的失敗現場，分辨第二次 QP 不可行來自模型、終端集合、物理限制或預測變動限制；修正從實際量測重新推演的初始預測軌跡。

| 組別 | 資料／控制方式 | 回答的問題 |
