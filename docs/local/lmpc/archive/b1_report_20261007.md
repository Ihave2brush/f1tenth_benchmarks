## 接線與前置核對

- Pure Pursuit 使用 core 版本中線 CSV 的 Cartesian 點，重用既有幾何 Pure Pursuit 計算；前視距離 0.6 m 為明列工程設定。
- 低速起步不進入原版 `[0,4]` 分支，所有實際控制區間的目標速度皆為 1.2 m/s。
- `CoreLapTracker` 重用 Continuous 的完整圈／partial／計時生命週期，以 core Frenet 投影作唯一進度來源。
- 起終點位置、方向、長度與六維狀態統一至 geometry_id `c53238c43d356997b7035bacb1907958cbc35d77d8f8916ec4691ca9c934de71`，L=236.907497773 m。
- 預檢 4,739 個中線樣本，最大間距約 0.049991031 m；曲線、精確 Frenet 反查與含餘裕的矩形車身檢查通過。
- 名義運動學轉向需求最大約 0.432410325 rad，4 個中線樣本超過 0.4 rad 命令上限。它是零追蹤誤差的幾何診斷，不是直接判定整圈不可行。實際閉迴路以小幅偏移跑通，無命令裁切。
- 矩形檢查使用分離軸測試檢查所有可能重疊的 occupied／unknown 格子，並拒絕地圖外車身，避免只查四角漏掉內部障礙。

## 證據與重現

本機證據位置：`Data/research/lmpc/b1_esp_centerline_20261007_001/`，共約 29 MB，不納入 Git。

- `session.json`：設定與來源、hash、驗收條件、實際指標及物理重播結果。
- `preflight.json`：中線候選及幾何轉向診斷。
- `samples.jsonl`：物理與論文六維狀態、Frenet、命令、各層致動器輸入、子步後繼與 steering buffer。
- `events.jsonl`：兩個完整圈事件、插值時間及對應實際物理樣本索引。
- `verification_final.json`：獨立原模型重播、Frenet／圈事件重建、時間／輸入／車身與追蹤界限核對，全部通過。
- `initialization_overview.png`：路線、側向誤差、速度及實際轉向。

從 repository 根目錄，在現有 Python 3.9 模擬環境執行；目標必須是新目錄：

```bash
python -B -m f1tenth_benchmarks.research.lmpc.run_initialization --output-dir NEW_SESSION
python -B -m f1tenth_benchmarks.research.lmpc.verify_initialization NEW_SESSION --output NEW_VERIFICATION_JSON
python -B -m f1tenth_benchmarks.research.lmpc.plot_initialization NEW_SESSION
```

本次使用既有 `f1tenth-frenet-inspector` 容器的 Python，將工作區唯讀掛在 `/workspace`，先寫入容器 `/tmp/track_b_b1_001`，完成後複製到上述本機目錄。26 項測試以 unittest loader 合併 `test_lmpc_interfaces.py`、`test_lmpc_initialization.py`、`test_continuous_laps.py` 執行。
