#### 錯誤原因與證據界線

1. **直接停止條件已確認：**第五次決策的第 4 個 ATV 查詢點是上述 x4；距離最近歷史資料的加權平方距離仍為 13.161311，超過目前 kernel 支持門檻 10，80 點權重全部為零。該點沒有新 ABC，第五次 QP 也沒有開始。
2. **上一層預測問題已確認：**第四次 QP 使用局部模型，允許中途狀態與指令離開局部訓練範圍；A32、A33 放大側向項，產生 −6.507121 rad/s。後續影子重播證明該預測與原始物理模型不符，不只是停止檢查過嚴。
3. **模型結構缺口已確認：**辨識以 delta_cmd 作輸入，卻未納入實際轉角及延遲記憶。原始模擬器會透過這些量決定車輪反應；細節見下方致動器段落。尚未做模型修正對照，不能將它寫成所有錯誤的唯一原因。
4. **目前沒有證據支持的解釋：**沒有發現此步 ABC 代入算錯或前次解移位錯誤；不能把異常預測解讀成車輛實際甩尾，也不能認定車輛已學會切內線。是否能藉改模型狀態修正，仍待離線對照驗證。

因此不是整個資料庫完全缺正轉向，而是此局部狀態附近控制覆蓋稀疏，而且「正目標指令」與「車輪已正轉」不相同。將點數增加，尚未證明能解決問題。

### 多步預測與敏感性

問題模型 A32 = 32.2535、A33 = 5.9664。其他量固定時，vy 差 0.01 m/s 會造成下一步 r 差約 0.3225 rad/s；r 差 0.1 rad/s 會造成下一步 r 差約 0.5966 rad/s。

固定重複同一模型的速度子矩陣最大特徵值約 8.1323，誤差強烈放大。此為壓力測試，不是論文的實際 ATV 流程，不能以它直接代替整段 ATV 驗證。

另以第四次 QP 的真正 12 步 ATV 與相同控制指令，比較原始物理模型影子重播，保留相同起始實際轉角與緩衝：

| 未來時間 | ATV 預測 r | 原始物理影子 r |
|---|---:|---:|
| 0.1 s | +2.02438 | +0.94893 |
| 0.3 s | −1.42753 | +2.37203 |
| 0.4 s | −6.50712 | +1.46843 |

單位均為 rad/s；12 步 Yaw Rate RMSE 約 2.76565 rad/s。後續影子狀態不是實際執行紀錄，也不構成成功圈。

### 信任區域比較

以下為同一 A3 初始狀態、同一延遲緩衝的離線影子比較，最多 8 個動作，沒有重跑完整圈。原 A3 vx 上限與加速度界限保留；WLS 選點與求解、Safe Set、Q-function 不變。

| 設定 | 額外限制 | 可執行影子動作 | 停止原因 |
|---|---|---:|---|
| 原 A3 | 無 | 4 | 第五次 kernel 支持不足 |
| 轉向範圍 | 局部轉向 min/max 外放 0.02 rad | 2 | 第三次 QP 無解 |
| 較寬名義區域 | vy ±0.05、r ±0.5，轉向外放 0.10 | 2 | 第三次 QP 無解 |
| 較窄名義區域 | vy ±0.02、r ±0.2，轉向外放 0.02 | 2 | 第三次 QP 無解 |
| 側向資料區域 | 局部 vy 外放 0.01、r 外放 0.1，轉向外放 0.02 | 1 | 第二次 QP 無解 |
| 完整資料區域 | 再加局部 vx 外放 0.1 | 0 | 第一次 QP 無解 |

速度單位 m/s、Yaw Rate 單位 rad/s；名義區域以各步名義點為中心。側向狀態信任區域作用 x1～x11，轉向作用 u0～u11；x0 為固定量測，終端仍使用原 Safe Set 等式。

從第四次決策前的同一狀態，只限制轉向可將最大預測 |r| 由 6.507 降到 3.982，下一次查詢均有 80 點有效權重，但再下一次仍 QP 無解。部分案例移除額外信任限制後恢復可行；另有案例移除後仍無解，不能一律歸因於信任區域過窄。

結論：尚無一組信任區域通過持續控制測試，不能當成已修正。所有額外限制僅存在離線腳本的記憶體中，正式控制器檔案雜湊保持不變。

證據：[完整離線分析與設定](/data/f1tenth/sim/f1tenth_benchmarks/Data/research/lmpc/experiments/A3_lmpc_20261015_001/offline_audit/audit.json)。

## 最新確認：轉向致動器與 WLS 狀態缺漏

目前路徑是：

```text
PP／LMPC 目標轉角 delta_cmd
→ 2 個物理步延遲緩衝（約 0.02 s）
→ 比較延遲目標與實際轉角
→ 依誤差符號使用 ±3.2 rad/s（誤差 <= 1e-4 時為零）
→ 實際轉角 delta_act 隨物理子步積分
→ 車輛動力學使用 delta_act 計算側向與 Yaw Rate 變化
```

轉向並非目標角立即生效。雖然函式名稱為 pid，轉向部分實際是固定速率、依誤差方向切換。

A3 第四次控制：起始實際轉角 −0.064 rad、緩衝舊目標 −0.054909 rad，新目標 +0.4189 rad。經過 0.1 s 後實際轉角為 +0.192 rad，並非 +0.4189 rad。

| 資訊 | 原始資料已保存 | 現行 WLS 有使用 |
|---|---|---|
| 目標轉角 command[0] | 是 | 是 |
| 當下實際轉角 physical_state[2] | 是 | 否 |
| steering_buffer | 是 | 否 |
| 物理子步實際角度與轉向速率 | 是 | 否 |
| effective_inputs 區間平均實際轉角 | 是 | 否 |

WLS 側向設計矩陣目前是 `[vx,vy,r,delta_cmd,1]`，未使用實際轉角與延遲緩衝。同一組六維狀態與當下指令，若隱藏的實際轉角／緩衝不同，下一步反應也可以不同。必須先處理這個模型接軌問題；僅將 delta_cmd 欄位改名為 delta_act 不會修正它。

區間平均實際轉角是已發生後才可計算的描述量，不應直接當作規劃時已知的未來輸入；如果改用實際角，仍需處理從目標指令到未來實際角的預測。

程式證據：[原始轉向緩衝與積分](/data/f1tenth/sim/f1tenth_benchmarks/f1tenth_benchmarks/simulator/dynamics_simulator.py:60)、[轉向控制](/data/f1tenth/sim/f1tenth_benchmarks/f1tenth_benchmarks/simulator/dynamic_models.py:189)、[車輛動力學使用實際角](/data/f1tenth/sim/f1tenth_benchmarks/f1tenth_benchmarks/simulator/dynamic_models.py:160)、[WLS 輸入讀取](/data/f1tenth/sim/f1tenth_benchmarks/f1tenth_benchmarks/research/lmpc/paper_model.py:82)。
