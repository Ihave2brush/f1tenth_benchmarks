# 本機幾何研究產物

正式的五張內建圖與 my_map 轉換檔統一位於 [maps/frenet](../../../maps/frenet/README.md)，
納入 Git；此目錄只保存本機研究輸出及歷史紀錄，僅本 README 納入 Git。

2026-10-07 整理前的所有研究目錄集中到
`archive/2026-10-07_before_publication/`，原數值檔案、manifest 與驗收紀錄不改寫。
歷史文件中儲存的路徑代表當時位置；搬移對照保存在 `archive/location_map.json`。
`archive/inspector_catalog.json` 是另外建立的可操作歷史檢視索引，不更動原索引。

新研究批次仍在此目錄內建立獨立輸出；驗證後再整理至 maps/frenet。
未驗證候選、疊圖、追蹤與 Stage C／D 歷史報告不混進正式地圖資料。
操作與座標規則見 [操作指南](../../../docs/project/usage.md)及
